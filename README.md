# 星渊战机 (Neon Strike)

微信小游戏 - 竖版弹幕射击游戏（类似雷电/1942）

## 项目结构

```
neon-strike/
├── game.js                  # 入口文件（加载 main.js）
├── game.json                # 游戏配置
├── app.json                 # 应用配置
├── project.config.json      # 微信项目配置
├── images/                  # 图片资源
├── audio/                   # 音频资源
└── js/
    ├── main.js              # 全部游戏逻辑（~1800行）
    ├── render.js            # 渲染模块（桩文件）
    ├── databus.js           # 数据总线（桩文件）
    ├── libs/
    │   └── tinyemitter.js   # 事件发射器（未使用）
    ├── base/
    │   ├── sprite.js        # 精灵基类（桩文件）
    │   ├── animation.js     # 动画类（桩文件）
    │   └── pool.js          # 对象池（桩文件）
    ├── player/
    │   ├── index.js         # 玩家类（桩文件）
    │   └── bullet.js        # 子弹类（桩文件）
    ├── npc/
    │   └── enemy.js         # 敌人类（桩文件）
    └── runtime/
        ├── background.js    # 背景类（桩文件）
        ├── gameinfo.js      # 游戏信息（桩文件）
        └── music.js         # 音乐类（桩文件）
```

> **注意**：所有游戏逻辑集中在 `js/main.js`，其他 JS 文件均为桩文件，尚未实现。

### 武器系统

游戏共 **4 大类武器** + 1 个可选武器空壳（UI 已实现，射击逻辑待开发）。

#### 一、主武器（Primary）

自动射击，100ms 间隔。升级方式：拾取 P 道具。

| 等级 | 弹型 | 说明 |
|------|------|------|
| Lv.1 | 2 发直射 | 并排双发 |
| Lv.2 | 5 发扇形 | ±20° 扩散 |
| Lv.3 | 10 发扇形 | ±30° 双排扩散 |
| Lv.4 | 追踪激光 | 自动锁定最近敌人，闪电链效果，伤害 2/tick |

#### 二、副武器（Secondary）

自动发射，2 秒 CD。升级方式：分数阈值。

| 等级 | 武器 | 分数门槛 | 效果 |
|------|------|----------|------|
| Lv.1 | 普通导弹 | 默认 | 直线发射 1 发，伤害 50 |
| Lv.2 | 散射高爆弹 | 100000 | 飞行屏幕 1/2 距离后散开为 8 方向子炸弹，延时爆炸，伤害 1 |
| Lv.3 | 追踪导弹 | 500000 | 自动追踪敌人，转向速率 4 rad/s，伤害 50 |

#### 三、僚机（Wingman）

分数激活，独立发射。升级方式：分数阈值。

| 等级 | 分数门槛 | 发射频率 | 说明 |
|------|----------|----------|------|
| Lv.1 | 100000 | 3 次/秒 | 2 架僚机（左右各一），跟随延迟 100ms |
| Lv.2 | 500000 | 7 次/秒 | 同上，激光频率提升 |
| Lv.3 | 1000000 | 10 次/秒 | 满级 |

僚机属性：激光白色，宽度 3px，持续 600ms/次，伤害 5。

#### 四、炸弹（Bomb）

手动触发（点击屏幕右上角区域）。消耗炸弹道具，不足 10000 分无法使用。

| 类型 | 分数要求 | 消耗 | 效果 |
|------|----------|------|------|
| 弱效清屏 | >= 10000 | 扣除 10000 分 | 清除所有敌弹 + 全场敌机受伤 50 |
| 完全清屏 | >= 50000 | 扣除 50000 分 | 清除所有敌弹 + 消灭所有敌机 + 清除所有道具 + 全屏爆炸 + 震动 |
| 核弹 | >= 100000 | 无消耗（独立按钮） | 全场敌机受伤 200 + 50 个爆炸粒子 + 强闪光 |

#### 五、可选武器（Weapon Selection）

底部右侧按钮打开武器选择弹窗，切换后改变主武器射击逻辑。

| id | 名称 | 描述 | DPS（Lv.3 单目标） | 实现状态 |
|----|------|------|-------------------|----------|
| standard | 标准弹 | 2~10 发扇形 / Lv.4 追踪激光 | 1000 | ✅ 已实现 |
| pierce | 穿透弹 | 直射穿透，伤害8，Lv.1=2发/Lv.2=4发/Lv.3=6发/Lv.4=8发 | 480（×敌人数） | ✅ 已实现 |
| ricochet | 弹射弹 | 碰壁反弹 2 次，伤害递增 | — | ❌ 空壳 |
| orbital | 护身弹 | 4 颗能量球环绕旋转 | — | ❌ 空壳 |

**穿透弹特性：**
- 每发子弹可同时命中多个敌人，命中 2 个等效 960 DPS，3 个反超标准弹
- 子弹不因命中销毁，追踪已命中敌机避免重复伤害
- 配合 Boss 阶段大量刷敌设计效果最佳

### 关卡设计规则

**核心规则：每关 30 秒小兵战 → Boss 登场**

| 阶段 | 持续 | 刷敌间隔 | 每波数量 | 说明 |
|------|------|----------|----------|------|
| prelude（前奏） | 8s | 1200ms | 1-2 | 热身 |
| push（推进） | 10s | 900ms | 2-3 | 加压 |
| climax（高潮） | 12s | 600ms | 3-5 | 高潮 |
| boss | — | — | 1 | Boss 战 |
| 合计 | **30s** | | | |

**敌机绘制：**
- Scout：小型三角战机，红色渐变，引擎火焰
- Fighter：中型战机，橙色渐变，侧翼结构
- Elite：圆形核心，紫色渐变，4条旋转臂动态效果
- Boss：大型战机，橙黄渐变，5引擎火焰，两侧炮台

**Boss 三阶段弹幕：**
- 阶段1（HP > 50%）：12路旋转圆弹
- 阶段2（HP 25-50%）：8路集中向下
- 阶段3（HP < 25%）：16路密集旋转

### 计分系统

- 基础分数：Scout 100 / Fighter 300 / Elite 1000 / Boss 5000
- 连击加成：每10连击 +10%
- 擦弹奖励：50分/次
- 道具翻倍：2x道具生效期间分数翻倍

### 难度递增

- 5 个主题关卡，敌机类型逐步解锁：Scout → Fighter → Elite
- 每关 30s 小兵战后 Boss 登场
- Boss 血量：3,000 → 60,000
- 通关后进入无限模式，难度随分数持续增长

### 关卡系统

采用 **5 个主题关卡 + 无限模式** 的结构，通过 StageManager 管理关卡流程。**已接入 game.js。**

#### 关卡统一时间线（每关 30s 小兵 → Boss）

| 阶段 | 持续 | 间隔 | 数量 | 说明 |
|------|------|------|------|------|
| prelude | 8s | 1200ms | 1-2 | 少量敌机热身 |
| push | 10s | 900ms | 2-3 | 数量和类型增加 |
| climax | 12s | 600ms | 3-5 | 精英机 + 密集弹幕 |
| boss | — | — | 1 | Boss 登场，击败后通关 |
| clear | 3s | — | — | 清屏，显示通关提示，进入下一关 |

#### 5 大主题关卡

| 关卡 | 敌机组合 | Boss HP | 特色 |
|------|----------|---------|------|
| Stage 1 — 前线突击 | Scout 为主 | **3,000** | 教学关 |
| Stage 2 — 小行星带 | Scout + Fighter | **8,000** | 弹幕压力上升 |
| Stage 3 — 敌方要塞 | Scout + Fighter + Elite | 中Boss **5,000** / Boss **20,000** | 精英中Boss |
| Stage 4 — 深渊舰队 | Fighter + Elite | 双Boss **30,000** + **15,000** | 双Boss 同屏 |
| Stage 5 — 最终决战 | Elite 为主 | **60,000** | 终极Boss 4阶段 |

#### 无限模式

- 通关 Stage 5 后解锁
- 敌机随机组合，难度随分数持续递增
- 每 50000 分触发一次随机 Boss

### 碰撞检测

使用 SpatialGrid（网格大小80px）优化：
- 玩家子弹 vs 敌机：圆-圆碰撞
- 激光 vs 敌机：线-圆碰撞
- 敌机子弹 vs 玩家：双半径（擦弹25px / 判定6px）
- 敌机 vs 玩家：机体碰撞
- 道具 vs 玩家：拾取半径30px

## 渲染

- **技术**：Canvas 2D API，纯程序绘制（无图片资源）
- **绘制顺序**：背景 → 道具 → 敌机 → 激光 → 子弹 → 粒子 → 玩家 → UI → 闪屏
- **特效**：引擎火焰闪烁、护盾脉冲、爆炸粒子、闪电抖动、全屏闪白

## 微信 API 使用

- `wx.createCanvas()` — 创建画布
- `wx.getSystemInfoSync()` — 获取屏幕尺寸
- `wx.onTouchStart/Move/End()` — 触控输入
- `wx.getStorageSync()` / `wx.setStorageSync()` — 本地存储最高分

## 操作说明

- 手指滑动控制飞机移动
- 自动射击，无需手动操作
- 点击右上角区域（屏幕20%宽×30%高）使用炸弹

## 运行方式

1. 使用微信开发者工具打开项目目录
2. 修改 `project.config.json` 中的 `appid`
3. 点击编译运行
